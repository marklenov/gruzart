# GRUZART v1 — лендинг с калькулятором

Реконструировано из переписки (грилл + прототип), формального тикета не было.

## Must

- Статический сайт, без сервера и БД (см. ADR 0001) — калькулятор считает в браузере, тарифы — в `src/data/tariffs.json`.
- Только городская перевозка, город — Астана. Межгород и такелаж — вне v1.
- 4 класса транспорта: минивэн, газель, газель увеличенная (4,2 м), грузовик — каждый с примерными размерами и почасовой ставкой.
- Умный калькулятор: клиент выбирает категорию груза (не кубометры/кг вручную) и число грузчиков (0–3) → получает оценку (часы × ставка класса + грузчики × часы × ставка грузчика, с минимальными часами) → переходит по готовой ссылке WhatsApp на номер +7 747 234 2353 с заполненным текстом.
- Категория «Коммерческий груз» не имеет фиксированной оценки — ведёт в WhatsApp без цены ("нужен индивидуальный расчёт").
- Переключатель языка рус/каз (рус по умолчанию), переключает весь видимый текст, а не отдельные страницы.
- Страница политики конфиденциальности — обязательна (планируется реклama/аналитика), реквизиты юрлица — плейсхолдер с явным TODO для замены перед запуском.
- Дизайн по выбранному прототипу — вариант A («калькулятор в хиро»): светлая палитра, инлайн-калькулятор рядом с хиро, обычный верхний навбар.
- Никаких придуманных отзывов или статистики («N лет на рынке», «500+ заказов») — GRUZART новый бренд, раздел отзывов — пустой плейсхолдер до реальных отзывов.

## Explicitly out of scope (backlog v2)

- Межгород, бизнес-кабинет (GRUZART BUSINESS), программа лояльности (GRUZART CLUB), живая карта машин, магазин упаковки, такелаж.

## Not specified (implementation judgement)

- Конкретные тарифы — плейсхолдеры в `tariffs.json`, подлежат правке владельцем.
- Технология рендеринга — решено: ванильный HTML/CSS/JS без сборки, максимально лёгкий хостинг.

# Статический сайт без сервера и базы данных для v1

GRUZART — лендинг с умным калькулятором стоимости грузоперевозки; требование — самый дешёвый возможный хостинг. Сайт-образец gruzim.kz сам устроен как обычный статический multi-page сайт без БД, что подтверждает жизнеспособность подхода для этого вида бизнеса. Решили: v1 собираем полностью статическим (калькулятор считает на клиенте по JSON-конфигу тарифов, заявка уходит в WhatsApp по готовой ссылке), без сервера и базы данных. Следствие: функции, требующие персистентного состояния — личный кабинет GRUZART BUSINESS, программа лояльности GRUZART CLUB, «живая карта машин» — не попадают в v1 и при реализации в backlog v2 потребуют отдельного архитектурного решения (сервер и БД).

# GRUZART

Сайт-лендинг для заказа грузоперевозок и сопутствующих услуг в Казахстане. По структуре — копия существующего сайта gruzim.kz, но со своим дизайном, умным калькулятором стоимости и без модуля такелажных работ.

## Домен

**GRUZART**:
Название сервиса/бренда. Основная услуга — грузоперевозки на газели (город и межгород); сопутствующие услуги — грузчики и доп. услуги по переезду.
_Avoid_: Gruzim, Gruzim.kz (это сайт-образец, не сам продукт)

**Умный калькулятор**:
Инструмент на сайте: клиент заранее выбирает маршрут и объём груза и получает ориентировочную стоимость перевозки без обращения в WhatsApp или по телефону. Ключевое отличие GRUZART от gruzim.kz — там стоимость называют только после заявки.
_Avoid_: просто "калькулятор" без уточнения входных параметров (маршрут + объём)

**Такелаж**:
Услуга перемещения тяжёлых или габаритных грузов через проёмы без лифта (кран, лебёдка, подъёмное оборудование). Есть у gruzim.kz, у GRUZART осознанно исключена из состава услуг.

**Городская перевозка**:
Перевозка в пределах одного города (на старте — Астана). Тарифицируется почасово.
_Avoid_: локальная перевозка

**Межгород**:
Перевозка между городами по одному из заранее заданного списка направлений. Тарифицируется по маршруту, без почасовой оплаты. Отложено — не входит в v1, только городская перевозка.
_Avoid_: дальняя перевозка, региональная перевозка
